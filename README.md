# Lead360 AI

Lead360 AI is a responsive front-end prototype for an AI-powered lead generation and sales intelligence workspace.

## Included

- Sales dashboard with illustrative metrics, acquisition trend, conversion funnel, and priority prospect list
- Prospect table filtering, navigation previews, and a simulated natural-language prospect search
- Responsive desktop and mobile layouts
- Sites static hosting configuration in `.openai/hosting.json`

## Run locally

Open `dist/index.html` in a browser. The prototype uses plain HTML, CSS, and JavaScript and has no install step.

## Demo data

All people, companies, counts, activity, and performance figures in the interface are fictional examples. Search and navigation interactions are client-side simulations. No live contact database, authentication, CRM persistence, messaging, billing, or third-party integrations are connected.

## Deployment

The Site is configured as a static deployment with `dist/` as its output directory. Publishing through Sites requires pushing this repository to the configured Site source remote, then saving and deploying the pushed revision.
